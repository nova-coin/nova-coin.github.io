First hybrid Scrypt PoW / PoS consensus coin. Private transactions. No premine.

Первая монета с гибридным Scrypt PoW / PoS консенсусом. Приватные транзакции. Без премайна.

Core Features

Ключевые особенности

Hybrid Consensus

Гибридный консенсус

PoW? only secures the network, while PoS? also reduces energy use and enables passive income.

PoW? только защищает сеть, тогда как PoS? также снижает энергопотребление и приносит пассивный доход.

Private Transactions

Приватные транзакции

Addresses starting with '5' are private. No mixers, no master nodes — pure P2P privacy.

Адреса, начинающиеся с '5', используют стелс-технологию. Без миксеров и мастернод — честная P2P-приватность.

Smooth Emission

Плавная эмиссия

No hard cap, no halvings. Rewards adapt to network difficulty via continuous curves, promoting long-term stability.

Без жёсткого потолка и халвингов. Награда плавно снижается с ростом сложности, обеспечивая долгосрочную устойчивость.
